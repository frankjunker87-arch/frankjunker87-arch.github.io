# FRANK_JUNKER — Sitio personal

**Hacker · Filósofo · Coder · Lover**

> Escribo código de día y poesía de noche. Me mueven la tecnología y las ideas que incomodan.

Sitio personal de Frank Junker con estética de terminal: estado «en línea», navegación por comandos y secciones estilo consola.

## Secciones

- `./perfil` — quién es Frank.
- `./proyectos` — su trabajo en código.
- `./playlist` — su música.
- `./redes` — dónde encontrarlo.
- `./colabs` — colaboraciones.

## El sitio

- Estático, en HTML y CSS, sin compilación.

| Archivo | Función |
| --- | --- |
| `index.html` | Página principal |
| `styles.css` | Estilos |
| `frank-cafe.jpg`, `nosotros.webp`, `img_chk/` | Imágenes del sitio |

## Cómo ejecutarlo

Abrir `index.html` en un navegador moderno, o servir la carpeta:

```bash
python3 -m http.server 8000
```
